# Linx Dispatch — Creative Copy Deck

Ten LinkedIn creatives for owner-operators and small fleet owners (1–10 trucks).
Offer: **Free Dispatch Fit Review** → `linxdispatch.com`

Every creative is 1080 × 1350 (4:5), rendered at 2× (2160 × 2700) in `out/`.
Source HTML in `build/creatives/`. Rebuild with `./build/render.sh`.

---

## How the ten are meant to run

They are not ten versions of one ad. Each attacks a different psychological
mechanism, so they can run as a full-funnel set rather than an A/B test of
the same idea.

| # | File | Mechanism | Funnel stage |
|---|------|-----------|--------------|
| 01 | `01-call-center` | Identity gap — who you meant to be vs. what you do all day | Cold / hook |
| 02 | `02-1147pm` | Validation — naming the exact moment they live | Cold / hook |
| 03 | `03-one-eighty` | Reframe — the loss wasn't a skill failure, it was a structural one | Cold / problem |
| 04 | `04-revenue-swing` | Proof by pattern — volatility as the real enemy | Warm / problem |
| 05 | `05-best-i-can-do` | Villain + specific proof — "+$440 per load" | Warm / proof |
| 06 | `06-before-after` | Direct comparison — the workhorse | Warm / consideration |
| 07 | `07-invisible-invoice` | Cost of inaction — the bill they already pay | Warm / urgency |
| 08 | `08-truck-owns-you` | Emotional reversal — freedom inverted | Cold / hook |
| 09 | `09-lasandra` | Authority + trust — a person, not a call center | Warm / trust |
| 10 | `10-fit-review` | The offer — low-friction close | Hot / conversion |

**Suggested first test:** 01, 05, 07, 10. One hook, one proof, one urgency, one offer.
